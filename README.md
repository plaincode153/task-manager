# Task Manager

A task manager built with vanilla JavaScript, HTML, and CSS.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed and undo completion
- Filter tasks by active/completed status
- Search tasks
- Sort tasks by due date
- Due-date status messages
- Form validation
- Local storage persistence
- Responsive layout

## What I Learned

This project helped me practice:

- DOM manipulation and event handling
- Array methods such as filter, find, findIndex, some, and sort
- Form validation and the Constraint Validation API
- Working with dates
- Local storage and JSON
- Creating and rendering DOM elements with JavaScript
- Filtering, searching, and sorting application data
- Basic responsive CSS
